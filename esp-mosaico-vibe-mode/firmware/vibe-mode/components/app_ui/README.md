# app_ui

管理 Vibe 自有轻量绘制器、设备显示、输入、截图及渲染调度；不依赖现成 UI 框架。
`ui_services` 将业务快照转换为界面模型，`vibe_ui` 是设备和 PC 共用的不透明控制器。
`light/vui.c` 与 `vui_decode.c` 使用同一资源包在两个平台运行。

PC 由 `pc/CMakeLists.txt` 将绘制器和页面控制器编译为本机动态库；
`pc/simulator.py` 通过 ctypes 调用它，把 RGB565 帧显示到浏览器 Canvas，
鼠标输入回传同一套 C 输入处理。`pc/platform_pc.c` 提供硬件服务的模拟快照。
浏览器 Boot 按钮按下时显示提示，松开后返回原页，与设备按键事件一致。
它不模拟 ESP32 CPU，也不运行设备固件二进制；布局和交互可以共用，
联网、Flash 写入、DMA 和面板时序仍需实机验证。

首页点阵由 `src/vibe_home_motion.c` 保存 49 个圆点的位置、半径、RGB 和亮度，
通过关键帧平滑插值生成入场组装、呼吸、斜向扫描及点击涟漪。绘制器的 `dots`
节点直接以亚像素边缘覆盖率绘制圆点，不再生成或解压首页位图动画帧。
40 ms 定时器按实际经过的毫秒数采样，仅在首页更新 120×120 区域；
离开首页（包括休眠）停止采样，返回时重播入场。点击从当前点状态开始涟漪，
不会截获页面滑动或阻塞导航。点状态与绘制器副本复用，无逐帧内存分配。

设置与显示页使用带 `scroll` / `content_height` 的容器；视口裁剪、绘制和点击
共用一个滚动偏移，标题栏不移动。与 Wi-Fi/Idea 列表共用拖动及定时减速逻辑；
点移动中的内容停止滚动，固定标题栏按钮仍立即响应。
列表只绑定可见行，滚动后按需重绑并释放离屏资源；隐藏列表不启动标题读取。
标题缓存保持八项，不随支持的十六项应用库扩大，避免全列表刷新引起循环淘汰。

应用图标直接显示打开确认框，不等待 NAND 扫描或后台更新检查。忙碌期间显示
等待状态且不接纳写入；扫描完成后刷新未保存开发版本提醒，用户需明确确认。
真正打开前重新读取状态，保留文件校验、低电量保护和写入互斥。

管理页的全部更新先显示确认页，确认后才开始检查和下载；返回、取消及 AI 键
均回到管理页。批量更新进行中，原按钮仍用于取消。开发版本保存期间提供取消；
保存完成或下载取消等只有“完成”操作的结果页使用居中宽按钮。下载状态紧接标题
下方并左对齐，只显示一处；百分比保持像素字体，进度条、字节数及速率分开排列。
批量任务入队后即可取消；若当前 Idea 已进入提交阶段，先完成该项，再停止剩余更新。
已完成的更新保留。共享信息删除后收敛页码；编辑草稿跨息屏和 Boot 提示保留，
返回编辑页后重新显示，真正离开该编辑上下文时清理。

公共业务依赖为 app_settings、app_device；私有适配依赖 app_network、app_ideas、
app_nand_update、app_system_update、app_bridge 和 BSP / display presenter / ESP-Iris 公共 API。
所有控制器与渲染操作由单个渲染任务串行执行；外部请求排队，旋转在帧间持锁执行。
资源复制、PNG 和 Canvas 的所有权规则见 `include/vui.h`；解码失败不接收调用方资源所有权。

设备入口为 `factory_ui_start()`；PC 使用 `vui_create()` 后调用 `vibe_ui_create()`。
生命周期结束先 `vibe_ui_deinit()` 再 `vui_destroy()`。渲染上下文不得与销毁并发。

长按、撤销及熄屏使用单调时间截止点，不以渲染回调次数计时。中途中断或再次进入删除
确认页时，倒计时提示与计时一同复位。页面切换保留同位置
重复点击的防穿透保护，新手势点击其他控件可立即响应。列表长标题仅使其可见标题
区域失效，局部渲染仍重建完整命中区域，保持其他按钮可用。

滑动只有在纵向位移超过点击容差且占主导时才接管，起步不显示已消耗的容差距离。
松手速度使用最近 100 ms 的固定样本窗口与独立的惯性启动门槛；慢拖松手即停，短暂尾部
抖动不会单独决定惯性方向。队列保留约 10 ms 间隔的运动检查点及手势边沿，惯性使用
固定点速度衰减，无逐帧分配。列表、网格与共享信息点击绑定按下时的稳定标识，扫描或
重排替换目标后取消该次点击；同一目标的标题、信号强度或进度刷新仍可正常点击。

首页与 Ideas 网格的横拖提供相邻页跟手预览，顶部状态栏和底部分页点保持固定；
距离或短快甩决定翻页，明确反向拖回会取消，边界提供有限阻尼而不产生额外页面。
松手按实际时间收尾，期间可重新抓取；图标点击不会穿透到预览页。首页点阵的点击互动
保留，明确横拖时将手势交给翻页。库条目替换、离开页面或硬件按键会取消当前预览，
纯容量、更新标记刷新不打断拖动。
一个按需分配并复用的 RGB565 帧缓存保存起始页，无逐帧分配；内存不足时退回无预览
导航，收尾定时器不足时立即完成松手判定，两者均保留防误触。

存储读取失败显示保留文件的说明与重试入口，不呈现为空库；存储不可用时禁止确认
下载和批量更新，云端简介仍可读取。外设设置区分启动中、不可用与可用状态；
初始化失败不会改写已保存的自动旋转或触感偏好。

结果页可执行的动作跟随已接受的操作。删除、保存开发副本及批量更新完成后只提供 Done，
不从历史选中项推导 Open；可打开的单个下载/检查结果仍保留 Open。

Ideas 的终态命令独立于后台当前命令。容量统计和标题读取不会将已抑制的删除成功终态
重新投影为弹窗；正常删除完成后留在库中。

固定中文欢迎副标题只烘焙实际文字，其余动态标签保留原有 ASCII 字符范围；不改变
资源格式或运行时绘制路径，新增提示仍遵守原有固定资源预算。
