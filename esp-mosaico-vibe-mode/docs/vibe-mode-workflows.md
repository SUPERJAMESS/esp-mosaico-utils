# Vibe Mode 使用、管理与开发流程（EMVM-73078）

本轮在现有 Vibe Mode 固件中实现同事演示的产品流程，复用已验证的
ESP-Iris、NAND 事务和 NOR 更新后端。演示工程只作为交互参考；
设备构建不包含 PC 模拟数据。Recovery ABI 2、layout version 5、
命令标识和 0x1c0000 字节的 Vibe Mode 固定分区不变。

## 交互与数据边界

首页有 Develop、Manage、Settings；左右滑动进入分页 Idea 网格。
点击 Develop 直接显示开发指南二维码和网址，底部实时显示 USB 未连接、
已连接等待 Agent 或 Agent 已就绪；不再提供 USB 安装与存入 NAND 的操作项。
首页和 Idea 网格的顶部栏在 Vibe Mode 后显示当前固件版本，页面标题以屏幕中线
居中，较长版本号省略显示，避免覆盖标题和连接图标。
底部分页标记按当前可见 Idea 数量计算，包含首页和末尾的添加入口：
空列表保留两页，Idea 页居中显示圆形加号与“添加 Idea”；普通网格每页六格，
最后一格之后始终保留添加入口。删除后同步减少页数，不保留空的占位页。
Manage 顶部显示实际容量与用量，更新角标来自真实可更新数量；列表用橙色标出
当前运行、可用更新及正在更新的状态，等待状态保持灰色。
进入 Manage 直接复用已加载的目录，不再每次触发完整扫描；首次进入尚未加载的
目录、内容变更、语言切换及固件更新仍会刷新，扫描失败后再次进入 Manage 会重试。
当前 Idea 用橙色边框标记。目录最多显示 16 个完整副本。长名称省略显示；
需要外部字形的名称在紧凑目录中使用编号，完整信息沿用云端 MIFF 展示资源。

开机按需加载目录；首次保存云端或开发副本前也会加载目录并检查实际数量，
避免未进入 My Ideas 时越过 16 个副本的上限。满库仍可更新已有副本。

| 操作 | 行为 |
| --- | --- |
| 输入六位编号 | 查询元数据并预览，用户确认后才下载；编号保留前导零 |
| 下载、单个更新、全部更新 | 只保存 NAND；下载及校验阶段可取消，当前副本的原子提交不可打断；批量更新可在当前项提交后停止，保留已完成更新 |
| 打开 | 校验 NAND；核对当前 NOR 的应用、分区表及资源，必要时写入，再自动重启 |
| 未保存开发内容时打开另一个 Idea | 只有“放弃并打开 / 取消”，不提供保存并打开；始终确认 |
| 普通打开确认 | 可设置以后跳过；电量保护仍生效 |
| 删除 | 当前 Idea 不可删除；长按三秒确认，四秒内撤销；离开页面、息屏或再次删除时提交 |
| Develop | 查看开发指南二维码和当前 USB 连接状态 |

恢复出厂的三秒长按进度直接填充在按钮内，不再显示按钮上方的提示和倒计时。
松手、移出按钮或离开页面都会清零；同一次长按最多触发一次恢复请求。

打开 Idea 时，NAND 文件校验逐块更新读取字节数、速率与已校验文件数。
校验 NAND 与核对 NOR 期间都可取消；点击后立即显示“正在取消”，工作任务在
读取块之间停止，不再追加目录扫描。取消结果不显示“打开”，点击完成返回首页。
实际写入 NOR 或提交启动选择前会关闭取消入口，保留现有写入与启动保护。

联网后自动检查云端发布；版本身份以 release ID 比较。批量更新串行处理
云端 Idea，页面显示当前行百分比与等待状态。可以切换页面；同一时刻只接纳
一个 Ideas 工作任务。本地开发副本不参与云端更新。

当有效电量读数不高于 20%，且未接 USB、未充电时，阻止打开写入流程。
电池、USB、Agent 状态来自 BSP 和 Iris，不使用演示常量。下载失败、
空间不足及校验失败会进入结果页；用户可返回管理页重试。

## 持久化与中断恢复

下载使用 `mosaico-ideas/device-release/1` 文件集合契约，预览一次获取 multipart 响应。先写
`/nand/ideas/<code>/.incoming`，逐文件验证长度和 SHA-256，写入描述与清单，
最后通过目录重命名提交 `current`。旧副本在提交前保留；取消不会改变旧副本。
首次下载失败会移除空目录。扫描恢复中断的替换并清理临时目录。

恢复仅在确认缺失、大小不符或摘要损坏时回退；内存、I/O、解析或摘要计算操作
无法完成时保留当前、旧版与日志，返回错误供重试。应用绑定日志读取失败不等于
新目录，不能借此覆盖同编号的其他应用。目录扫描失败或达到遍历上限时保留旧
快照，不把不完整目录用于新增保存的容量准入。

删除在撤销窗口结束后将 `current` 原子更名为 `.deleted`，再清理其有界文件；
重启扫描继续清理。未知子目录不会递归删除。

删除保护在 NOR 读租约内查询启动记录并校验；NVS/NOR 读取失败或更新占用时
停止删除，仅明确证明启动记录已过期时放行旧副本。

开发保存使用仅供本地读取的 `mosaico-ideas/local/2` 描述，编号为
`d` 加五位十六进制字符，发生冲突时寻找其他编号，不覆盖无关 Idea。
固件清单单独保存到 `firmware/manifest.json`，本地名称与描述使用原生文本显示。
持有 NOR 读租约后读取实时分区表、验证应用镜像、复制资源并计算摘要，
提交前再次核对源数据。它不复制 bootloader、Vibe Mode、设备元数据、
NVS 凭据、OTA 选择器或崩溃记录。支持最多八个固件组件，沿用现有
32 MiB 包边界；不会声称保存了超出边界的布局。

打开同一版本也核对资源摘要；只修改资源同样会被识别为未保存开发内容。
保存和快速启动与 Iris OTA、系统写入互斥。写 NOR 沿用单运行槽的维护启动意图，
并不提供 A/B 回滚。设备断电验证仍是发布新预置包的必要步骤。

读租约先占用产品写入所有权，再检查 Iris OTA 状态。Iris 的 C 状态查询把已接纳的
BEGIN 阶段也视为 active，覆盖开始擦除但尚未创建活动 OTA 状态的窗口；
尚未创建 OTA 服务的离线启动仍允许读取。协议标识和线上结构不变。

同版本快开在 NOR 校验后继续持有读租约，直到重启，防止其他写入者在校验与
启动之间修改目标。快开也会清理失败维护操作遗留的启动意图；清理失败时停止
重启。NOR 读取、分配或校验操作失败时直接报错，仅摘要不匹配才转为重装。
系统更新的每次写入与组件结束都要求描述符完整匹配已批准计划，大小、
位置、类型等字段不能在接收阶段改变，写入边界以已批准的大小为准。

## 设置与共享信息

首次启动默认 English，并将语言写入 `sysmeta/vibe_prefs/lang`；设置页面可切换
简体中文，重启后保留选择。已有设备的语言偏好会迁移并保留。查询云端时使用
`en` / `zh-CN`。设备偏好写入 `sysmeta/vibe_prefs`：

- 亮度 20 / 40 / 60 / 80 / 100%，默认 80%；息屏保持 10% 背光。
- 无操作 1 / 3 / 5 / 10 分钟或永不息屏，默认三分钟。
- 自动旋转、触感、普通打开确认，默认开启。
- 息屏断开网络，触摸、AI 键或拿起唤醒后恢复连接；写入和输入期间限制旋转。

息屏会取消尚未获取 IP 的配网请求；唤醒只加载已保存的凭据，避免把待连接
网络误当成实际恢复的网络再次保存。没有凭据时恢复为未配置状态；驱动停止或
启动、凭据读取或连接配置失败会保留错误并允许重试，设备任务以一秒间隔重试
失败的休眠状态切换，直到恢复过程完成。

设备任务采样电池、IMU 和 USB；按键使用 40 ms 去抖和有界事件队列。
旋转在帧间等待显示提交完成，由 presenter 同步显示与触摸方向，再完整重绘。
触感使用计时器提供按键、确认、拒绝、成功、失败反馈；可关闭。
可选传感器不可用不会阻止 USB 维护启动。

共享信息写入 `sysmeta/shared`，支持 16 项自定义值，另保留两个 Wi-Fi 字段。
键为 1–15 字节的
`[a-z0-9_]`，值最多 256 字节；屏幕键盘支持 ASCII 输入。
包含 key/token/secret/pass/pwd 的键默认遮盖值，可手动显示。退出编辑清理
显示缓冲；日志和模拟器状态快照不输出共享值。删除也提供确认和撤销。

消费应用依赖现有 `esp_mosaico_app_recovery` 组件即可使用：

```c
#include "mosaico_shared.h"

char api_key[257];
esp_err_t err = mosaico_shared_get("api_key", api_key, sizeof(api_key));
/* ESP_ERR_NVS_NOT_FOUND：尚未设置；ESP_ERR_NVS_INVALID_LENGTH：缓冲不足。
 * 按应用需要使用，勿写入日志；不再需要时清理缓冲。 */
```

接口只读，不擦除、不缓存、不打印值；所有 Ideas 共享同一命名空间。

Wi-Fi 连接成功后保存 `wifi_ssid` 和 `wifi_password`，共享信息页面自动刷新；
`wifi_password` 默认遮蔽，开放网络的密码为空字符串。旧 `sysmeta/wifi` 配置
在共享值提交成功后迁移并清理。启动和息屏唤醒直接读取共享字段，手动编辑后
在下次启动或息屏唤醒时使用；“忘记网络”只删除这两个共享字段，不影响其他共享值。
应用可用 `mosaico_shared_get("wifi_ssid", ...)` 和
`mosaico_shared_get("wifi_password", ...)` 读取，缓冲区分别至少 33 / 65 字节。
这两个保留字段在设置服务写入前校验：SSID 为 1–32 字节，密码为空、8–63 字节，
或 64 位十六进制。无效修改不会覆盖已保存凭据；普通共享值仍允许 256 字节。

## 恢复出厂设置

长按三秒确认，先取得 NAND 与 NOR 的互斥租约，再写入持久化 reset 标记和
Vibe Mode 启动意图，停止 Wi-Fi 自动重连与凭据保存。仅清理
`wifi`、`shared`、`vibe_prefs` 三个 NVS 命名空间，并取消
`iris_bridge_v2/pending_boot` 这一条临时远程启动请求。
成功后重启恢复英文默认设置；中途断电或提交失败，下次启动继续完成清理。

**完全保留 NAND Flash**，包括 Ideas、开发副本和其他用户文件；
保留 NOR 应用、当前 Idea 启动记录、设备身份与 Iris 配对身份。
该实现没有 NAND 格式化、分区擦除或身份重建调用。

设备默认保留 WARN/ERROR 日志，
